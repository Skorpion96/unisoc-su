**unisoc-su poc app**

This is a poc app for this method, it has a mini terminal built in and 2 buttons, one tries to connect to the system shell with the script already on this repo, the other runs the ghostroot (to be noted that the ghostroot is relatively safe on this app, i had to do heavy modifications, i don't know if it's for this reason or because the terminal is too simple but cmd_services is correctly logged). There is also a mini help section because why not.

Made with Claude AI and some chatgpt help (tough Claude went crazy and flagged two times, because even a patched exploit is bad seems... Tough, this only affects legitimate research, the bad ones will abuse AI anyway...)
